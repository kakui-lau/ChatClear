# ChatClear（群清）品牌说明

ChatClear 的图形标志使用深森林绿圆角底板与暖象牙白符号。两段对话气泡弧线形成清晰的
“整理 / 确认”动作，表达安静、克制和由用户主动决定的群组清理体验；它有意避开 Telegram
纸飞机、垃圾桶和扫帚等容易造成官方隶属或粗暴删除联想的元素。

## 色彩

- Forest Green：`#176B52`
- Warm Ivory：`#FFFDF5`
- Muted Coral（仅作状态强调）：`#C85B4B`

## 文件

- `assets/brand/chatclear-logo-master.png`：原始高分辨率品牌资产
- `public/chatclear-logo.png`：应用内与文档使用的 256 px 图标
- `build/icon.png`、`build/icon.icns`、`build/icon.ico`：各平台打包图标
